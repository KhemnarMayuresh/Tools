# गीतकारिका editor design

Approved scope: safe autosave/migration; selected-section editing and reordering; TXT/JSON import/export and print PDF; formatting; undo/redo; search/counts/focus; themes/mobile; user documentation. User explicitly requested implementing these steps; proceed inline without another approval cycle. Keep current feature checkout, no commit/push/deployment.

## Document and data safety
Static vanilla HTML/CSS/JS, no network assets or dependencies for play. Preserve the existing Unicode HTML filename and URL. Model `{version:1,sections:[{id,title,collapsed,width,height,blocks:[{id,html,align,width}]}]}`. IDs unique across document; title <=200 code points, <=100 sections, <=500 total blocks, <=200000 HTML code units/block, <=2000000 total HTML code units. Sizes are null or finite integers (width140–1600; section width240–1600; height120–1600). Alignment left/center/right. Strict JSON validation, limits before render; imports <=4MiB. Atomic replace confirmation and downloadable JSON backups. TXT import adds one plain-text block to selected section (create section when empty). No DOCX, IndexedDB or tags in this iteration.

Sanitize HTML at every restore/import/paste boundary with inert DOMParser and rebuild nodes: text, br, p/div, strong/b, em/i, u and spans with font-size14/16/20/24px only. Discard scripts/styles/media/forms/SVG/control buttons and legacy delete controls; unwrap other elements, drop all handlers/URLs. Never render unsanitized HTML. Editable content and controls are siblings. Titles and messages use textContent. Plain-text paste preserves line breaks; rich clipboard markup is ignored.

Use namespaced `geetkarika-document-v1` localStorage key. Legacy `sections` is read only when new key is absent; migrate title/text/IDs safely, generate replacement IDs for duplicates, remove embedded delete buttons, retain legacy key. Loading does not save until successful edit or explicit recovery choice. Corrupt storage is retained and offers raw recovery download; cannot silently overwrite it. Storage failures retain in-memory edits, visible unsaved status and JSON export. Debounce saves400ms; synchronous flush on visibility/pagehide; pageshow re-establishes actionable UI without losing text. Storage event reports external changes rather than overwriting current edits.

## Editing and history
Sections stack/grid responsively; sidebar actions selected-section-aware with Add text on every section. Dedicated handles draggable; drop sections reorder, blocks insert/move to empty or collapsed sections. Drop guard validates identity; no contenteditable drag. Keyboard move up/down plus Move to section select. Collapsing/focus does not delete content. Optional native resizing desktop with sizes captured at pointer release; mobile clamps presentation without overwriting stored dimensions. Explicit size inputs for keyboard accessibility.

Formatting uses selected range (bold/italic/underline wraps selection; font size wraps span) and whole-block alignment. No range means show a selection hint without touching another block. Retain selection on toolbar interaction, including keyboard focus. Typing remains native contenteditable; composition never interrupted by render/sanitization. Save after compositionend. Undo/redo document snapshots cover all edits and structural operations, grouped per editable target within1000ms; limit50 steps and8MiB retained history (current document never dropped). Focus/caret restored where possible. Undo Ctrl/Cmd+Z, redo Ctrl/Cmd+Shift+Z or Ctrl/Cmd+Y only within workspace; native historyUndo/Redo intercepted. No stealing shortcuts in search/dialog inputs.

Search literal, case-insensitive across titles/block text; next/previous results focus/reveal target, no injected highlight HTML and no content mutation. Counts use Intl.Segmenter wordlike segments where available, whitespace fallback; characters Unicode code points including whitespace. Hindi/emoji literal and safe. Focus mode isolates chosen section, Escape exits; no fullscreen permission needed.

## Interface and verification
Top-right Light/Dark/System icons44px with aria-pressed, validated optional preference. Clear selected section, save status, empty state, labelled block controls, visible focus, inline modal confirmation with focus trap/Escape/cancel restoration. 375px/640x360 no horizontal page overflow. Print shows all sections/text regardless collapse/focus, removes controls, themes/pagination readable; browser print provides Save as PDF. Animation respects reduced motion.

Acceptance: preserved legacy text with one delete control/block; add/move/edit selected sections; roundtrip safe JSON/TXT; reliable undo and paste/composition; accurate save status and recoverable bad storage; readable theme/mobile/print. Node pure-module tests and real Edge browser tests exercise these and existing repository regressions.
